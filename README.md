# St. Leo's College Kyegobe - Official School Website

*Course:* BIT 2103 - Internet Technologies & Advanced Website Development
*Client:* St. Leo's College Kyegobe (Fort Portal, Uganda)
*Stack:* WordPress, Hello Elementor, Custom PHP 8+ / MySQL (PDO/MySQLi), Custom CSS

## Site Architecture
- Home, About Us, Services, Gallery, Contact Us, Student Registry, News & Updates
- News Categories: School News, Academic & UNEB, Sports & School Life

## Repository Structure
- /custom-css: Brand styling (#718e3a Emerald Green & #d4af37 Gold) and responsive layouts
- /crud-module: Custom PHP/MySQL Student/Alumni Registry CRUD module and SQL schema
- /docs: Client Brief, Proposal, NDA, and Staff Handover Manual
